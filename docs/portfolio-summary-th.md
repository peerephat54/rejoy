# ReJoy สำหรับ Portfolio

ReJoy เป็นแอปสนับสนุนสุขภาพใจที่พัฒนาด้วย Flutter, Node.js, Express และ MongoDB Atlas โดยเชื่อมประสบการณ์ของผู้ใช้กับระบบสำหรับบุคลากรทางคลินิก ฟีเจอร์หลักประกอบด้วย Companion Chat ที่มี AI Safety, แบบคัดกรอง PHQ-9 แบบใช้กฎที่อธิบายได้, ภารกิจ Micro-CBT, เกาะที่เปลี่ยนตามแนวโน้มอารมณ์, ระบบ SOS แบบออฟไลน์, รายงาน PDF และ Clinical Dashboard ที่แยกสิทธิ์ผู้ใช้

จุดเด่นทางวิศวกรรมคือการออกแบบ Red-Flag Interception ก่อนส่งข้อความไปยัง AI, การแยกข้อมูลตามผู้ใช้และบทบาท, refresh token, secure storage, MongoDB connection pooling, local cache, aggregate monitoring ที่ไม่เก็บข้อความดิบ และ release-signing workflow สำหรับ Android

## ข้อความเกี่ยวกับ NSC ที่ใช้ได้อย่างซื่อตรง

"โครงการ ReJoy ผ่านการคัดเลือกเข้าสู่รอบภูมิภาคภาคใต้ของ NSC แต่ไม่ได้เข้าร่วมนำเสนอ เนื่องจากไม่สามารถส่งเอกสารได้ทันกำหนดจากปัญหาทางระบบ หลังจากนั้นได้นำข้อบกพร่องมาปรับปรุงด้านเสถียรภาพ ความปลอดภัย และกระบวนการ deploy ต่อ"

ไม่ควรเขียนว่าได้รับรางวัล ผ่านรอบนำเสนอ หรือเป็นตัวแทนระดับประเทศ หากไม่ได้เกิดขึ้นจริง
